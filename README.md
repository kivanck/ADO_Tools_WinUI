# ADO Tools - Azure DevOps Productivity Suite

A Windows desktop app (WinUI 3) for everyday Azure DevOps work at Bentley: browsing and downloading work items,
semantic search over the backlog, comparing commits, and downloading and installing product builds.

## Download

**[Latest release](https://github.com/kivanck/ADO_Tools_WinUI/releases/latest)** - download the
`ADO_Tools_WinUI_<version>_x64.zip`, extract it and double-click the `.msix`.

The package is signed by **Bentley Systems, Incorporated**; no certificate import or administrator rights are needed.
